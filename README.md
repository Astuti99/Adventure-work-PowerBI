# 🚴 Adventure Works Power BI Dashboard

## 📌 Project Overview
This Power BI project provides an interactive business intelligence dashboard for Adventure Works sales data.  
The dashboard analyzes sales performance, customer behavior, product trends, profitability, and return analysis to support data-driven business decisions.

The project focuses on transforming raw business data into meaningful insights using data visualization and analytics techniques.

---

# 🎯 Project Objective
The main objective of this project is to:

- Analyze sales and revenue performance
- Identify top-performing products and categories
- Track customer purchasing behavior
- Monitor return quantity and return rate
- Compare weekday vs weekend sales trends
- Generate business insights through interactive dashboards

## 🔍 Dashboard Highlights
- Category-wise revenue analysis

## 📌 Key Insights
