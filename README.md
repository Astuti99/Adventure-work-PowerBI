# Adventure Works Power BI

## 📌 Project Overview
This project analyzes sales performance, customer behavior, product trends, and revenue insights using Power BI.  
The dashboard helps businesses make data-driven decisions by identifying top-performing products, customer segments, and sales patterns.

---

## 🎯 Project Objective
The objective of this project is to analyze sales, customer behavior, product performance, and revenue trends using interactive Power BI dashboards to support business decision-making.

---

## 🛠️ Tools Used
- Power BI
- Excel
- DAX
- Data Cleaning
- Data Visualization

---

## 📈 Key Insights
- Sales trends analysis
- Product performance comparison
- Customer segmentation
- Revenue and order analysis
- Return quantity and return rate analysis
- Country-wise order tracking

---
